- CoinGecko + Binance + Kraken + Coinbase market-data cross-checking/fallbacks.
- Binance and Kraken order-book pressure/microstructure endpoint.
- Alternative.me Fear & Greed Index.
- GitHub developer-activity endpoint with optional token authentication.
- GDELT + RSS news discovery on every scan.
- Optional OpenAI structured event extraction; deterministic scoring remains final authority.
- Optional web-push subscriptions and signal notifications.
- Optional single-user password protection for public cloud deployment.

- Mobile UI cards for market mood, data-source health, alerts and performance.
