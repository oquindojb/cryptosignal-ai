# v0.7 — Intelligence UI redesign

- Genuine mobile-first terminal redesign; not a restyle of the previous dashboard.
- Prominent ACTIONABLE NOW decision area on mobile.
- Live market ticker with horizontally scrollable mobile cards.
- One-tap Scan Now command button and full-scan action inside Actionable Now.
- Market Radar replaces the old desktop-heavy watchlist table on the primary interface.
- Signal Feed separates evidence-driven signals from market overview.
- Bottom navigation: Home, Radar, Signals, Track.
- Service-worker cache bumped to v0.7 so installed PWAs can receive the new UI.
- Backend API version bumped to 0.7.0.
