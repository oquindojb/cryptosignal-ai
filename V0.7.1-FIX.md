# CryptoSignal AI v0.7.1 — Live Connection Fix

Fixed a frontend JavaScript error in v0.7 that prevented `bootLive()` from running.
The redesigned page called a removed `#assetTable` element during startup, which stopped JavaScript execution and left the status permanently at “Connecting”.

Changes:
- Removed obsolete `renderTable()` call/function.
- Added a visible frontend error handler.
- Bumped static cache/version to 0.7.1 so browsers and the PWA service worker receive the fix.
- Backend version updated to 0.7.1.

No API keys are required for the public exchange endpoints. Keep secrets out of GitHub.
